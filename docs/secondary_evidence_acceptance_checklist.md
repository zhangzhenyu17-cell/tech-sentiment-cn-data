# 931152 secondary evidence acceptance checklist

A membership node may move from pending to complete for historical research only after all applicable checks pass:

- exact effective date matches the preregistered node;
- source URL/query is reproducible;
- raw response or durable SHA256 is retained when available;
- evidence role is explicit (first-party, candidate pool, interval cross-check);
- candidate fund holdings are not treated as index membership without independent confirmation;
- at least one independent source cross-check supports the reconstructed set or add/remove interval;
- adjacent-node reconstruction is internally consistent;
- any source conflict remains fail-closed and documented;
- 2024+ holdout data is not read by the reconstruction or qualification path;
- qualification grants historical-research input eligibility only, never production or trading authority.
